Click the file name to start the download. Your browser may ask for confirmation. If so, agree and wait for the download to finish.

Once the download completes, open your Downloads folder and double-click the installer file (it will look like `kian-setup.exe` or similar).

## 🛠️ Troubleshooting

If kian does not open or crashes, try these steps:

1. Restart your computer.  
2. Check that your antivirus software allows kian to run.  
3. Make sure you installed the latest version from the downloads page.  
4. Verify your internet connection is working.  
5. If the problem persists, uninstall kian via Settings > Apps and reinstall using the steps above.  

For detailed help, visit the GitHub page or create an issue.
